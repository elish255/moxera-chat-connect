# Moxera Connect

Nitengenezee website ya Moxera agencies, hii inahusu kuchat na Wazungu Kiswahili na unalipwa, weka foreigner wa kuchat nao, ila mtu akigusa start chat itafunguka chat na foreigner ataanzisha Mazungumzo kwa kiswahili

User atajibu, Kisha akigusa send itamwambia ili aendelee kuchat inabidi ajisajili kwa Activation fee ya elf 16,000, Ili aweze kuchat na kulipwa

Button ya JISAJILI SASA itampeleka user ukurasa wa Registration ambapo atajaza taarifa zake kama picha inayoonesha, Baad ya kujisajili ndipo username yake itaonekana kwenye dashboard na ataweza kuchat na kulipwa 

Dashboard iwe kama hiyo picha ya kozena, kwenye maneno kozena utaweka Moxera, pia dashboard itamkaribisha user aliyojisajili kulingana na username aliyojisajili nayo 

Hizo tikto Facebook ziwe ndo foreigners atakaowachagua kuchat nao, foreigners wawe wanabadilika Kila mara, Mazungumzo yawe realistic
